Installation

Build from source or run via container.

Downloads

Pre-built binaries for Windows, Linux, and macOS are available on the GitHub Releases page. Download the latest release for your platform and run it directly — no build step required.

# Example: run the downloaded binary
./surisc -u https://example.com

Source

Compile using the included Makefile. Requires Go 1.21+.

make all      # compile into dist/surisc.exe
make clean    # clean build outputs
make test     # run unit and E2E tests

Docker

docker build -t surisc .
docker run --rm surisc -u https://example.com

Podman

podman build -t surisc .
podman run --rm surisc -u https://example.com

GitHub Container Registry

Run directly without building locally.

docker run --rm ghcr.io/marcuwynu23/surisc:latest -u https://example.com
podman run --rm ghcr.io/marcuwynu23/surisc:latest -u https://example.com
