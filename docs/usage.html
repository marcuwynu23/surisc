Usage

Running scans and interpreting results.

Basic scan

Perform a full reconnaissance scan against a target URL.

# Basic reconnaissance scan
surisc -u https://example.com

# JSON output for programmatic consumption
surisc -u https://example.com -o json

Security profiling

The -i flag skips secret scanning and focuses on target profiling. Supported scopes:

  • -i or -i all All informative sections
  • -i serverinfo Infrastructure and security headers
  • -i routes Discovered routes and hidden path probe results
  • -i robots robots.txt audit
  • -i sitemaps sitemap.xml audit
surisc -u https://example.com -i
surisc -u https://example.com -i serverinfo
surisc -u https://example.com -i routes
surisc -u https://example.com -i robots
surisc -u https://example.com -i sitemaps
